# 🌤️ CloudChaser - Weather Application

CloudChaser is a sleek, responsive web application that provides real-time weather information, smart daily advice, and dynamic background animations tailored to live weather conditions.

---

## ✨ Features

* **Real-time Weather Data:** Search and fetch live weather conditions for any city globally using the Open-Meteo API.
* **Dynamic Background Themes & Animations:**
  * 🌧️ **Rainy Theme:** Real-time CSS raindrop animations during rain or thunderstorms.
  * 🌌 **Night Theme:** Twinkling stars animation during night hours.
  * ☀️ **Sunny & ☁️ Cloudy Themes:** Smooth color gradient transitions based on day/night cycles and cloud cover.
* **Smart Weather Advice:** Contextual recommendations based on temperature extremes, rain probability, and wind speeds.
* **Temperature Unit Toggle:** Instantly switch between Celsius (°C) and Fahrenheit (°F).
* **Detailed Metrics:** Tracks humidity percentage, wind speed, rain chance, sunrise, and sunset times.
* **Extended Forecast:** View weather trends for **Yesterday** alongside the **Next 5 Days**.
* **Glassmorphic UI:** Modern UI design featuring frosted glass panels, glowing accents, and CSS backdrop blurs.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3 (Flexbox/Grid, Keyframe Animations) .
